# Challenge the reasoning

Read the selected target, its sources, and applicable agreements first. Identify unsupported claims, conflicting requirements, hidden assumptions, weak boundaries, and alternatives. Use the owner's actual experience and confirmed decisions; do not invent a suggested answer as research.

Ask only questions whose answers could materially change the work. Start with the most consequential uncertainty, offer a clearly labelled interpretation if useful, and respect a time or question limit. Stop when the useful uncertainty is resolved rather than exhausting a generic questionnaire.

For a brief, record a Requirements Handshake with Confirmed constraints, Open questions, and Assumptions being carried forward in the selected brief/handshake target. Preserve source versions. For an agreement, propose precise line changes and apply substantive revisions only with owner approval. For other claims, return the sharpened reasoning or edit the authorized target.
