# Wrap up a session

Write to the relevant project log, or the career-vault log for career work. Do not put one client's notes in another project or write actual sessions into the new-client template.

Add a dated entry at the top using Did, Decided, Open, and Next. Use the user's current local date. Preserve older entries. Record decisions only when the owner actually made them; distinguish proposals, implementation, verification, and publication status. A saved file is not necessarily merged or deployed.

For an authorized handoff, save routine factual notes directly. If a consequential decision is unclear, ask about that specific uncertainty before recording it as settled. Keep the final reply brief and name the log.
