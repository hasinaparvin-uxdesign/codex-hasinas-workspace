# Evaluate usability heuristics

Read the actual design, its version, the user task, and the applicable brief and principles. Assess system status, real-world language, user control, consistency, error prevention, recognition, efficiency, minimalism, error recovery, and help.

For each heuristic record evidence, impact, a concrete recommendation, and Pass, Needs work, Fail, or Not verified. Explain the severity scale if assigning one. Do not equate an unverified behavior with a proven usability failure or silently convert another report's scale.

A static design supports observations about visible content, not claims about unobserved transitions, focus, assistive technology, or usability testing. Summarize the highest-impact issues and validation needed in the project's critique record. Leave implementation and owner decisions distinct from recommendations.
