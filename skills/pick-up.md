# Pick up a session

Find the project named by the owner, or use the active project folder. Exclude the new-client template and practice-bank index. If several real projects are plausible, ask one focused question. Career work uses the career-vault log.

Read the newest log entry, then the files it names and the applicable agreements. Compare the handoff with current files and Git state; a log can be stale. Describe what was done, the confirmed decision, what remains open, and the next useful action. Do not ask the owner to repeat known context.

This workflow is read-only. It does not resume deferred product work without a request. If no handoff exists, say so and orient from actual documents rather than inventing yesterday's session.
