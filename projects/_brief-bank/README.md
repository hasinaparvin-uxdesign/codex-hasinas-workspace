# Optional practice briefs

This folder mirrors the example workspace's practice-brief area. These are optional exercises, not portfolio projects, client requirements, or evidence of completed work.

The original exercises remain in the [reference brief bank](https://github.com/hasinaparvin-uxdesign/claude-for-designers/tree/423b1de2aa9b4bf1050fd046987fb4f3a404ffec/projects/_brief-bank): logistics dashboard, skincare storefront, B2B landing page, and home-services booking.

Ask to start an exercise if useful. Codex should then create a clearly named project from the [new-client template](../_new-client/README.md), record that it is a practice project, and preserve the exercise source. Do not mix those fictional clients into Styra or claim them as professional experience.
