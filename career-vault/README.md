# Career vault

This is the reference workspace's six-part career structure with original, unfilled templates. These files contain no invented employment, client, research, or outcome claims.

| File | Purpose |
| --- | --- |
| [01-positioning.md](01-positioning.md) | Professional direction and evidence of strengths |
| [02-portfolio-story.md](02-portfolio-story.md) | Master structure for an evidence-based project story |
| [03-resume.md](03-resume.md) | Verified experience, projects, skills, and education |
| [04-interview-answers.md](04-interview-answers.md) | Actual decisions, trade-offs, outcomes, and interview preparation |
| [05-linkedin-content.md](05-linkedin-content.md) | Profile and post drafts in the owner's voice |
| [06-proposal.md](06-proposal.md) | Client proposal structure without assumed commercial terms |
| [log.md](log.md) | Career-work session handoff |

Codex can help fill these when asked, using the owner's evidence and project logs. Optional future project stories belong in a portfolio-stories subfolder; job drafts belong in an applications subfolder when there is an actual application. The [application-pack workflow](../skills/application-pack.md) must identify missing evidence and prepare drafts only, without sending or applying.

This repository is public. Keep private contact details, confidential work, and sensitive employment material out unless the owner explicitly intends to publish them. Creating these templates does not authorize filling or sharing personal information.
